Datenschutzerklärung – Jarvis

Stand: 20. Oktober 2026

Wer nutzt Jarvis? Jarvis ist eine private Anwendung für genau eine Person, den Betreiber. Sie wird niemand anderem angeboten.

Welche Daten? Mit Zustimmung des Betreibers greift Jarvis auf dessen eigenes Google-Konto zu: Kalendertermine (lesen, anlegen, ändern, löschen), E-Mails (lesen) und E-Mail-Entwürfe (anlegen). Jarvis versendet keine E-Mails.

Wo werden die Daten verarbeitet? Auf einem eigenen Rechner oder eigenen Server des Betreibers. Für die Auswertung werden Ausschnitte an einen Sprachmodell-Anbieter (Anthropic) übermittelt, ausschliesslich im Auftrag des Betreibers.

Weitergabe: Die Daten werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben, ausser an den genannten Sprachmodell-Anbieter zur Verarbeitung.

Speicherdauer: Zugangsdaten und Arbeitsstände liegen nur so lange vor, wie der Betreiber Jarvis nutzt. Der Zugriff lässt sich jederzeit unter myaccount.google.com → Sicherheit → Drittanbieter-Apps widerrufen.

Google-API-Daten: Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
